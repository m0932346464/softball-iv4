名次規則（秩序冊）：勝 3 分、和 1 分、敗 0 分；得分、失分、防守局數隨每局回報即時累計，勝和敗與積分在按下「比賽結束」後計入。積分相同依序比較：① 勝負關係（同分隊伍間的對戰）② 總失分少 ③ 總得分多 ④ 總防守局數多 ⑤ 抽籤。「名次依據」欄標示是哪一項分出高下。

紀錄表上傳

紀錄員從打擊落點紀錄按「上傳」後出現在這裡

選左邊一份上傳的紀錄表，確認球員對應後按「匯入」。

歷史落點 CSV 匯入

把過去的紙本紀錄整理成 CSV 一次匯入。欄位：日期、場次、隊伍、對手、先後攻、局、棒次、背號、姓名、結果、落點、打點、左右打（必填：日期、隊伍、背號或姓名、結果）。左右打填 左、右 或 左右，可留空；有填的會同步更新球隊名單。結果與落點用紀錄表代號，例如 1B、F、K、HR，落點 78、8D、108XD；三振、保送落點留空。沒有的球隊、場次與球員會自動建立；同一份檔案重複匯入不會重複。

已匯入的批次

球員跨屆對照

系統預設用「同隊（含別名）＋同姓名」把別屆的打席算給本屆球員。下面列出需要人工確認的情況：同名不只一位、或背號相同但姓名不同。按「是同一人」會把那一屆的資料算進來；按「不是」就排除。

封存本屆與備份

「匯出打席 CSV」和上方的匯入範本同格式，可以直接再匯入；「完整備份」包含球隊、名單、賽程、打席與上傳紀錄。建議每屆結束封存後，把兩個檔案存到社團雲端。
